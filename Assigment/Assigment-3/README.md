# Assignment 3: Navya Jauhri Portfolio

## Run

```bash
npm install
npm start
```

Open `http://localhost:3000` in a browser to view Navya Jauhri's B.Tech Computer Science and Engineering portfolio.

The portfolio page is served from `public/index.html`, with styles in `public/styles.css`. The server also exposes the profile data at `GET /api/profile`.
